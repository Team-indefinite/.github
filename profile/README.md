# Team-indefinite

로컬 데이터 분석 기반 상권·입주 적합도 분석 서비스를 만드는 팀입니다.

## 프로젝트 소개
유동인구, 업종 분포, 임대료, 치안, 소음, 날씨 등 로컬 공공데이터를 AI로 분석해서, 창업할 곳을 찾는 사람과 살 집을 찾는 사람 모두에게 "이 지역이 괜찮은지"를 점수로 보여주는 서비스를 만들고 있습니다.

기존 상권 분석 서비스는 창업자만, 부동산 서비스는 입주자만을 위한 정보를 제공합니다. Team-indefinite는 두 관점을 하나로 합쳐, '현재 상태'뿐 아니라 인구 구조 변화 등 '앞으로 어떻게 변할지'까지 예측하는 서비스를 지향합니다.
